# Lancement du Dashboard Streamlit

Le projet CryptoBot inclut un dashboard développé avec **Streamlit** afin de visualiser les données du pipeline Data Engineering.

Le dashboard permet d'afficher :

- les statistiques du marché (prix, volume)
- l'évolution du prix du Bitcoin
- un aperçu des données récupérées par l'API
